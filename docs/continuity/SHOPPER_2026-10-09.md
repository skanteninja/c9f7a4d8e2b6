Delayed scans cannot overwrite newer offers. Slot replacement preserves observation history.

## 0.14.2 — persistent nickname and reviewed learning examples

User requires the nickname prompt only once, including across updates; all later changes through scanner Settings. `nickname_setup_seen` is persisted before opening the first dialog, so cancel/restart does not repeat it. Saved nicknames from older releases migrate silently. Settings includes Change nickname and a persisted sharing toggle.

Confirmed listing uploads optionally include allowlisted OCR readings and top candidate scores (sharing defaults on for this project). The same authenticated upload transaction records a public, sanitized learning example in a new SQLite table; normal idempotency prevents duplicate samples. `/api/market/learning?after=N` exports reviewed examples with a monotonic cursor. No extra GitHub credentials are shipped with the scanner. `.github/workflows/sync-scanner-learning.yml` archives JSON and item-row crops under `learning/scanner/examples` approximately every five minutes, using Actions' temporary token. Full screenshots, local settings, private keys and auth contributor IDs are excluded. Archived data is for future evaluation/code improvements, not automatic model training.
