AGENT BRIDGE

Persistent guide maintenance

The website is your actual guide. A connected Google Sheet remains hidden behind it as a headless maintenance source so ChatGPT can reliably update guide data in future sessions. The website code is backend-agnostic, so that source can be replaced later without rebuilding the interface.

Maintenance contract

Guide research is maintained separately from your personal playthrough. Quest checks, selected level, held ETC counts and equipped items stay in your browser and must survive guide updates. The current maintenance source is the connected Sheet; it is not part of the user-facing workflow.
